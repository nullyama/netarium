Netarium 1.5.0 の機能案内

「どこに、何が、どうつながっているか」を
ひとつの場所で。

機器の台帳と構成図を関連付けて管理するWebアプリです。設置場所、IPアドレス、配線、保守情報をたどりながら、日々の確認や引き継ぎに使えます。

このページは紹介用です。下の画像はリポジトリに同梱された実画面のスクリーンショット。保存・ログイン・Pingなどの本体機能はここでは実行しません。

図から、機器の情報をたどる

機器を選ぶと、右側の情報が切り替わります。Netarium本体が持つ「図と台帳がつながる」考え方を試すための小さな見本です。

メモはこのページを開いている間だけ保持します。サーバーへの送信・実機への接続はありません。

ほかにも、こんな使い方

やりたいこと既存の機能
配線を追いかけるポート・VLAN・接続系統の管理、接続線の経路調整
IPを整理するネットワーク区分・セグメント管理、登録済みIPの一覧
変更を振り返る機器・ビューの変更履歴、Configテキストの世代管理と差分
更新時期を把握する保守期限のダッシュボード、台帳への絞り込み
引き継ぎ資料を作るCSV出力、印刷・PDF用プレビュー、構成情報のバックアップ

常時監視ツールではありません。Pingは利用者が明示的に実行する疎通確認です。

追加したら面白そうなIssue案

既存機能を足がかりにした提案です。以下は未実装の案で、Issueの投稿はまだしていません。既存Issueとの重複は投稿前に確認します。

01　「このスイッチを止めたら？」を試す構成図シミュレーション

接続関係の強調を一歩進めて、選んだ機器やケーブルを仮に停止したとき、登録済みの図で影響を受けそうな範囲を表示します。

  • 仮停止の選択・解除で、候補機器とたどった経路を表示する。
  • 実機への操作やPingは行わず、保存された構成を変更しない。
  • 冗長経路・VLAN・ルーティングの未登録条件を明示し、実際の通信断とは断定しない。
02　架空の庁舎データで始める、お試し環境と操作ツアー

空の画面から始めるハードルを下げます。架空のフロア・ラック・機器を含む独立したデモ環境で、「機器を探す→配線をたどる→設置場所を見る」を案内します。

  • デモ専用データを用意し、既存の業務データへ混ぜない。
  • 操作の説明と、最初の状態に戻す機能を備える。
  • 実IPへの疎通確認や外部接続を無効化する。
03　変更前後を並べて見る、ネットワーク構成図の比較

既存の変更履歴とは別に、2時点の構成図を並べ、機器・接続・配置の追加や変更を視覚的に示します。工事前後の説明や引き継ぎに使えます。

  • 比較する2時点のスナップショットを明示して保存・選択する。
  • 機器の同一性をIDで照合し、追加・削除・属性変更・移動を分ける。
  • 比較は読み取り専用。履歴のない過去の図を復元できるとは扱わない。

本物のアプリを動かすには

PHP 8.5.5以上とSQLiteが必要です。公式にDockerとWindows Server / IISに対応しています。GitHub Pagesでは、この紹介ページは公開できますが、Netarium本体は動作しません。
